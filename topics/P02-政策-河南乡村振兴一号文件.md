# 2026年河南省委一号文件摘要

> 说明：本篇依据实际年份为 2026 的现行版本撰写——《中共河南省委 河南省人民政府关于锚定农业农村现代化 扎实推进乡村全面振兴的实施意见》（2026年2月12日），2026年5月30日由河南日报受权发布、河南省政府网站群转载。所有数字与政策名均有来源，未作推测。

## ⚡ 快速知识卡

2026年河南省委一号文件是"十五五"开局之年指导全省"三农"工作的纲领性文件，以推进乡村全面振兴为总抓手、以学习运用"千万工程"经验为引领，部署六大板块：持续提升粮食综合生产能力（粮食面积稳定在1.6亿亩以上、产量稳定在650亿公斤以上）、把农业建成现代化大产业（6大产业集群、18条乡村富民产业链）、统筹建立常态化防止返贫致贫机制、宜居宜业和美乡村建设（2026年培育35个先导区）、农村重点领域改革（第二轮土地承包延包30年整省试点）与党建引领基层治理。它把中央一号文件精神河南化、具体化，是选调考试"三农"主题的最高优先级政策文本：粮食安全、防返贫、和美乡村、延包试点四条线都从这里出题。

## 📖 深度专题

### 一、政策背景

- 文件全称与成文时间：《关于锚定农业农村现代化 扎实推进乡村全面振兴的实施意见》，成文于2026年2月12日，2026年5月30日公开发布[SE17][SE18]。
- 顶层语境：贯彻习近平总书记关于"三农"工作的重要论述和视察河南重要讲话精神，聚焦"1+2+4+N"目标任务体系，坚持农业农村优先发展、城乡融合发展，锚定农业农村现代化[SE17]。
- 三个"总牵引"：以推进乡村全面振兴为总抓手，以学习运用"千万工程"经验为引领，以改革创新为根本动力；总目标是"守牢粮食安全底线，持续巩固拓展脱贫攻坚成果，提升乡村产业发展水平、乡村建设水平、乡村治理水平"[SE17]。
- 时间节点意义：2026年是巩固拓展脱贫攻坚成果同乡村振兴有效衔接5年过渡期后转向常态化帮扶的第一年，文件专章部署常态化防止返贫致贫机制[SE19]。
- 底盘数据（文件发布之际的河南"三农"基本面）：河南粮食总产量稳居全国第二，连续9年稳定在1300亿斤以上；"十四五"期间新建、改造提升高标准农田3167万亩；农业科技进步贡献率67%，主要农作物良种覆盖率超97%，耕种收综合机械化率90%，三项指标均高于全国平均水平[SE19]。

### 二、核心目标与数字

- 粮食硬指标：确保粮食播种面积稳定在**1.6亿亩以上**，粮食产量稳定在**650亿公斤以上**（即1300亿斤以上）[SE17]。
- 百亿斤粮食产能提升工程：建设1500万亩小麦、100万亩水稻、2000万亩玉米、80万亩大豆高产示范区[SE17]。
- 产业目标：打造粮食等**6大产业集群**、小麦等**18条乡村富民产业链**；发展设施种植业促进农民增收三年行动[SE17]。
- 和美乡村：2026年培育**35个**宜居宜业和美乡村建设先导区，实施"千村引领"和美乡村建设行动；到2030年建成先导区120个，先导区内村庄率先具备现代生活条件，建设和美村5000个、辐射带动富美村1万个、洁美村1.5万个[SE17][SE19]。
- 帮扶资金：将省级财政衔接推进乡村振兴补助资金调整为省级财政**常态化帮扶资金**，保持省市两级投入规模稳定[SE17]。
- 延包试点：启动第二轮土地承包到期后再延长三十年**整省试点**，到**2028年**全省基本完成延包工作[SE17]。
- 民生背景数据：2025年河南农村居民人均可支配收入22550元，增长5.7%，城乡收入比缩至1.95[SE19]。

### 三、重点任务（六大板块二十六条）

1. **持续提升粮食综合生产能力**（第一至五条）：粮食大面积单产提升行动（向科技、管护、防控、市场要粮）；严守耕地红线、严格占补平衡，整治"大棚房"、耕地"非农化"、永久基本农田"非粮化"，以"投建运管"一体化机制建高标准农田；强化农业科技与装备支撑——推动中原农谷、周口国家农高区协同发展，建强国家生物育种产业创新中心，推进神农种业实验室资源整合，建好洛阳现代农机装备国家先进制造业集群；增强防灾减灾能力；完善完全成本保险、最低收购价、产销区省际横向利益补偿等强农惠农政策[SE17]。
2. **加快把农业建成现代化大产业**（第六至十条）：重要农产品稳产保供（生猪产能调控、奶业纾困）；发展乡村富民产业，实施农村电商高质量发展工程，培育"小而美"文旅业态；大力发展设施农业；打造"豫农优品"区域公用品牌；分类发展县域经济（大城市周边县、区域重点县、专业功能县、农业大县、重点生态功能区县五类施策）[SE17]。
3. **统筹建立常态化防止返贫致贫机制**（第十一至十四条）：健全常态化帮扶政策体系，守牢不发生规模性返贫致贫底线；完善监测体系，做到早发现、早干预、早帮扶，建立动态调整机制；提升产业和就业帮扶质效（落实"四个一批"、帮扶项目资产全周期管理、以工代赈扩面）；确定一批省级乡村振兴重点帮扶县，开展"组团式"帮扶和科技特派团"产业式"帮扶[SE17]。
4. **因地制宜推进宜居宜业和美乡村建设**（第十五至二十条）：片区化推进、组团式发展、先导区引领；城乡供水一体化、"四好农村路"、客货邮融合；县域普通高中振兴、医疗卫生强基工程、大学生乡村医生专项计划、县乡村三级养老服务网络；整治改厕、垃圾围村、污水；深化"五基四化"、持续深化"五星"党支部建设、公务员招录计划向县乡基层机关倾斜、不得从县乡借调工作人员；推进移风易俗、整治高额彩礼，坚持和发展新时代"枫桥经验"，深化"党建+网格+大数据"模式[SE17]。
5. **推进农村重点领域和关键环节改革**（第二十一至二十六条）：延包三十年整省试点（2028年基本完成）；农村集体经营性建设用地入市（严禁建商品住房）、宅基地规范审批；发展新型农村集体经济、整治"三资"问题；建设现代农事综合服务中心（支持周口市整域先行先试）；"政银担保投"联动支农；推动城乡要素双向流动——实施"三支一扶"、乡村振兴村级协理员、大学生志愿服务乡村振兴等人才计划[SE17]。
6. **加强党对"三农"工作的全面领导**：五级书记抓乡村振兴，省负总责、市县乡抓落实；用好乡镇履职事项清单、村（社区）工作事项准入制度，整治形式主义为基层减负；开展"清廉河南"基层建设行动[SE17]。

### 四、与河南选调的关联

- **高频出题区**：选调生岗位在乡村一线，文件中粮食安全党政同责、防返贫"早发现早干预早帮扶"、和美乡村先导区、"五星"支部建设、移风易俗都是案例分析与材料写作的直接命题语境。
- **基层减负与人才政策可作答"如何留住基层干部/人才"**：文件明确公务员招录向县乡倾斜、不得从县乡借调工作人员、落实村干部基本报酬保障、实施村级协理员等计划——回答"基层治理""青年到村去"类题目的现成对策。
- **改革类考题**：延包整省试点是全国唯一的整省试点层次的政策（河南地位特殊），结合"整体 CSP：稳面积、优结构、提单产"理解河南作为粮食大省的政治责任。
- **与政府工作报告互为印证**：报告（P01）中"建成35个先导区、1000个和美乡村""新建改造高标准农田400万亩以上"与一号文件同口径，两文对照记忆可同时覆盖常识题两个出题源。

### 五、可考角度

- 常识：文件全称与印发时间（2026年2月12日）；粮食面积1.6亿亩、产量650亿公斤（1300亿斤）双底线；6大产业集群、18条乡村富民产业链；延包整省试点、2028年基本完成；2026年35个先导区。
- 案例分析：给定某县高标准农田"投建运管"一体化或农事综合服务中心材料，考查分析"谁来建、怎么管、如何长效"；给定防返贫监测案例，考"早发现、早干预、早帮扶"机制设计。
- 材料写作：以"学习运用'千万工程'经验，建设宜居宜业和美乡村"为主题，按"产业富民—建设塑形—治理铸魂"三分论点展开，各论点引文件原文支撑。

### 六、金句/对策

1. "守牢粮食安全底线……把农业建成现代化大产业、使农村基本具备现代生活条件、让农民生活更加富裕美好"——适用于乡村振兴总论、农业强国主题开头。[SE17]
2. "向科技要粮、向管护要粮、向防控要粮、向市场要粮"——适用于粮食安全、藏粮于技主题的分论点骨架。[SE17]
3. "做到早发现、早干预、早帮扶，守牢不发生规模性返贫致贫底线"——适用于底线思维、民生保障主题。[SE17]
4. "摒弃'千村一面'的粗放建设模式，坚持片区化推进、组团式发展、先导区引领，打造各具特色的现代版'富春山居图'"——适用于乡村建设、因地制宜方法论主题。[SE17][SE19]
5. "办好农村的事情，实现乡村振兴，关键在党"——适用于基层党建、乡村治理主题的升华段。[SE17]
