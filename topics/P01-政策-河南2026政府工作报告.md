# 2026年河南省政府工作报告摘要

> 说明：本篇依据实际年份为 2026 的现行版本撰写——2026年1月26日河南省第十四届人民代表大会第四次会议上，省长王凯所作《政府工作报告》，全文由河南日报发布、河南人大网转载。数字与政策名均标注来源，未作推测。

## ⚡ 快速知识卡

2026年河南省政府工作报告是"十五五"开局之年的总部署。报告回顾"十四五"（GDP达6.66万亿元、粮食连续稳定高产）与2025年（GDP增长5.6%、粮食产量1350.97亿斤），提出2026年经济增长5%左右、粮食产量1300亿斤以上等预期目标，部署融入服务全国统一大市场、扩内需、现代化产业体系、乡村全面振兴、城乡区域协调、改革开放、文化、绿色转型、民生、防风险等十个方面重点工作。核心框架是"1+2+4+N"目标任务体系。选调考试中，本篇是时政常识题的直接题源，也是申论论述河南定位（粮食安全、统一大市场、新质生产力、黄河战略）时引用目标与数据的权威依据。

## 📖 深度专题

### 一、政策背景

- 会议时间与主体：2026年1月26日，河南省十四届人大四次会议开幕，省长王凯作政府工作报告[SP01][SP02]。
- 时间节点意义：2026年是"十五五"开局之年；报告同时审查《河南省国民经济和社会发展第十五个五年规划纲要（草案）》[SP02]。
- 总纲：报告明确聚焦"1+2+4+N"目标任务体系，贯彻习近平总书记在河南考察时重要讲话精神和关于河南工作的重要论述，落实中部地区加快崛起、黄河流域生态保护和高质量发展等国家战略部署[SP02]。
- "十四五"收官基础：生产总值6.66万亿元，财政总收入7019亿元，经营主体1160.5万户，常住人口城镇化率60%，"米"字形高铁网全面建成，高速公路通车里程突破1万公里[SP02]。

### 二、核心目标与数字（2026年主要预期目标）[SP02]

| 指标 | 目标 |
|---|---|
| 经济增长 | 5%左右，努力争取更好结果 |
| 规上工业增加值 | 增长6.5%左右 |
| 固定资产投资 | 增长5%左右 |
| 社会消费品零售总额 | 增长5.5%左右 |
| 一般公共预算收入 | 增长4%左右 |
| 城镇调查失业率 | 5.5%左右 |
| 城镇新增就业 | 110万人以上 |
| 居民消费价格涨幅 | 2%左右 |
| 粮食产量 | 1300亿斤以上，力争比去年更多增长 |
| 居民收入 | 增长与经济增长同步 |

2025年实际完成数（报告回顾部分）：GDP增长5.6%，规上工业增加值增长8.4%，工业投资增长13.3%，进出口总值增长14.1%，粮食产量1350.97亿斤，主要指标增速居全国前列[SP02]。注意区分：1350.97亿斤是2025年"已完成数据"，1300亿斤以上是2026年"目标值"。

"十五五"展望：经济年均增长5%左右，农业强省、制造强省、科教强省、数智强省、交通强省、文旅强省建设取得实质性进展；如期实现2030年前碳达峰目标[SP02]。

### 三、重点任务（2026年十个方面）[SP02]

1. **纵深推进融入和服务全国统一大市场**：制定融入服务全国统一大市场建设行动方案；实施营商环境优化提升行动、规范涉企执法行动（"扫码入企"、"一业一查"）；建设物流、消费商贸、要素配置、产业链接四类枢纽；打造"空中丝路"融汇支点等三大支点。
2. **大力拓展内需增长新空间**：提振消费专项行动、消费品以旧换新、推广胖东来经验；实施1000个以上省重点项目、年度完成投资1万亿元；推进平漯周、焦济洛平等高铁项目，开工建设南信合高铁。
3. **加快建设现代化产业体系**：建强先进制造业、现代服务业、数智赋能、科技支撑四大体系；国家高新技术企业达到1.5万家、科技型中小企业3.2万家；数字经济规模2.5万亿元；技术合同成交额力争3000亿元；实施100项省级重大科技专项。
4. **扎实推进乡村全面振兴**：实施百亿斤粮食产能提升工程，推进66个粮食产能提升重点县和豫东平原200万亩整区域高标准农田项目，新建改造高标准农田400万亩以上；壮大6大特色产业集群和18条乡村富民产业链；建成35个先导区、1000个和美乡村；新改建农村公路5000公里、村级寄递物流综合服务点3万个以上；守牢不发生规模性返贫致贫底线。
5. **着力推动城乡区域协调发展**："一主两副"（郑州国家中心城市，洛阳、南阳）；"一圈两带"（郑州都市圈、郑开同城化）；支持巩义、永城、林州等10个县（市）发展成为中等城市。
6. **统筹推进深层次改革高水平开放**：启动新一轮国资国企改革行动；实施促进民营经济高质量发展行动计划；**全面开展第二轮土地承包到期后再延长30年整省试点**；常态化推进"高效办成一件事"；中欧（亚）班列开行4000班次；新增有进出口实绩企业1500家以上。
7. **全面激发文化创新创造活力**：支持郑州、开封、洛阳、安阳创建国家文物保护利用示范区；擦亮"行走河南·读懂中国"品牌；建设黄河古都群文化旅游目的地。
8. **加力促进经济社会全面绿色转型**：大气污染治理提质增效；深化幸福黄河三年行动；可再生能源发电装机突破1亿千瓦；新培育绿色工厂200个、绿色工业园区10个。
9. **更大力度保障和改善民生**：新增农村劳动力转移就业40万人，职业技能培训200万人次；接续实施乡村振兴村级协理员、万名大学生助企服务专项计划；省属公办高校生均经费增加1000元；启动基本医疗保险省级统筹；完善三级养老服务网络。
10. **有力有效防范化解重点领域风险**：安全生产治本攻坚三年行动收官；完善全口径地方债务监测，完成地方政府融资平台退出；加强党建引领基层高效能治理，扎实推进"五基四化"，坚持和发展新时代"枫桥经验"。

### 四、与河南选调的关联

- **面试/申论素材直接来源**：选调生到村任职、基层治理岗位的核心语境就是报告中的乡村全面振兴、和美乡村、"五基四化"、防止返贫等部署；引用报告原文（如"守牢不发生规模性返贫致贫底线"）能显著提升作答权威性。
- **身份契合点**：报告明确"接续实施乡村振兴村级协理员""公务员招录计划向县乡基层机关倾斜"（一号文件），选调生正是这批基层力量储备的组成部分，可在自我认知与岗位匹配题中引用。
- **省情定位题**："1+2+4+N"目标体系、"一主两副""一圈两带"、六大强省（农业/制造/科教/数智/交通/文旅）是河南定位类题目的标准框架。
- **热点呼应**：第二轮土地承包延包30年整省试点、全国统一大市场（河南行动方案）、"空中丝路"均为2026年度河南特有热点，中央政策+河南落地的组合最常考。

### 五、可考角度

- 常识：2026年河南粮食产量目标（1300亿斤以上）；"十四五"末河南GDP总量（6.66万亿元）；2025年GDP增速（5.6%）与粮食产量（1350.97亿斤）；"米"字形高铁网全面建成。
- 案例分析：以"1000个省重点项目、年度投资1万亿元"分析扩大有效投资的路径；以"四类枢纽+三大支点"分析河南如何融入全国统一大市场。
- 材料写作：围绕"经济大省挑大梁""现代化河南建设"组织分论点——稳粮食基本盘、强产业集群、活县域经济、惠民生底线，每个分论点都可回扣报告数据。

### 六、金句/对策

1. "扛起了经济大省挑大梁责任"——适用于大作文论述河南担当、区域协调发展主题。[SP02]
2. "让民事无忧、企事有解、政事高效"——适用于营商环境、数字政府、服务型政府主题。[SP02]
3. "守牢不发生规模性返贫致贫底线"——适用于巩固脱贫成果、乡村振兴底线思维主题。[SP02]
4. "推动经济实现质的有效提升和量的合理增长，实现'十五五'良好开局，奋力谱写中原大地推进中国式现代化新篇章"——适用于高质量发展、开局起步类结尾。[SP02]
5. "树立和践行正确政绩观，坚持为人民出政绩、以实干出政绩"——适用于基层干部作风、政绩观主题。[SP02]
